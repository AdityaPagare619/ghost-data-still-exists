The auditor that proves a negative.

A customer asks to be deleted, the dashboard says Complete, and weeks later the same email is still “already registered.” This atlas shows the machine that answers are we sure? — with a dated piece of evidence for every claim, and a proof that nothing can come back. Straight answer first: the engine is built and gated on the 32 samples, and this demo runs it live. The figures below are the architecture the running code implements.

The chiefs' lenses — where each expert sits in the machine

Oracle / Spanner chief

Bitemporality is the schema. Valid time vs transaction time, deletes as superseding rows, per-record horizons. CHRONOS proved the corpus has no transaction positions — so lag vs drift is never claimed per row.

Amazon chief

Disagree, test, commit. Every dissent settled by a read-only test against the 32 samples, then the 518. Where samples are silent, the safest non-destructive default commits and Horizon B records the doubt.

J.P. Morgan chief

Two-tier state machine. Rich internal states (UNVERIFIED_REPLICA, ARMED_FLOW, RETAINED_BLOCKED_RECHECK_DUE…) project deterministically to three verdicts. A gate left open can never project to COMPLETE.

Cravath chief

Closed universe, two horizons. Horizon A adjudicates only what is observable; Horizon B confesses everything unobservable (cache with no state table, untestable blocks, missing fields) without changing a single verdict.
